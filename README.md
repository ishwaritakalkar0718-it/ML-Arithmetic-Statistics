# Arithmetic and Statistical Calculations Using Python

## Aim
To configure a Python environment using Anaconda and Jupyter Notebook and perform arithmetic and statistical calculations.

## Tools Used
- Anaconda Distribution
- Python
- Jupyter Notebook
- Statistics module
- NumPy

## Operations Performed
- Addition, subtraction, multiplication and division
- Floor division, modulus and exponentiation
- Mean, median and standard deviation

## Dataset
[10, 20, 30, 40, 50]

## Results
- Mean: 30
- Median: 30
- Population standard deviation: 14.14

## Conclusion
Arithmetic and statistical calculations were successfully implemented using Python and Jupyter Notebook.
